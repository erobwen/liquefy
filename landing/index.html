Liquefy

Two generations of a reactive, JavaScript-first front end framework - with state management built in.

The new generation

Cascade

Built on the world's first temporal signals: readers and writers of the same data, ordered in time. So Cascade renders straight onto the live DOM in one pass - a parent can measure the room it has and hand it to its children, in the same pass - while a change still touches only what changed.

  • Programmatic, reactive layout from real measurements
  • Transition animations, with nothing animated knowing about it
  • Themes that replace whole components - and are their colors
Try the demo Documentation npm

The generation before

Flow

What you get if you take all the capabilities of MobX + React and integrate them into one unit: components that build reactively, auto-observed state, minimal DOM updates and transition animations - without the overhead of temporal signals.

  • Auto-observed state - change anything, from anywhere
  • Minimal updates, to the DOM and the component tree
  • For context free UIs, built context free
