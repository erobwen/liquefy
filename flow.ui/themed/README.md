# themed-ui

Themed widgets for [Flow](https://github.com/erobwen/liquefy/tree/main/flow.core#readme):
`button(...)`, `card(...)`, ... asked for from whichever theme is set up - see
[@liquefy/ui-material](https://github.com/erobwen/liquefy/tree/main/flow.ui/material#readme).

```console
npm install @liquefy/themed-ui @liquefy/basic-ui @liquefy/flow.dom @liquefy/flow.core @liquefy/causality
```
