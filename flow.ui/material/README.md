# ui-material

A Material Design theme for [Flow](https://github.com/erobwen/liquefy/tree/main/flow.core#readme),
built on [mdui 2](https://www.mdui.org/) web components: buttons, inputs,
cards, lists, dialogs, app bars and navigation.

```console
npm install @liquefy/ui-material @liquefy/basic-ui @liquefy/flow.dom @liquefy/flow.core @liquefy/causality
```

```js
import { button } from "@liquefy/ui-material";
```

It imports mdui's stylesheet, so it needs a bundler that handles CSS imports
(Vite and webpack both do).
