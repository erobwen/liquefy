# basic-ui

Basic widgets and layout for [Flow](https://github.com/erobwen/liquefy/tree/main/flow.core#readme):
layout (`row`, `column`, `filler`, `centerMiddle`, `zStack`, ...), buttons,
inputs, cards, alerts, list items, dialogues, popovers, overlays, modals and
portals - plain HTML, lightly styled.

```console
npm install @liquefy/basic-ui @liquefy/flow.dom @liquefy/flow.core @liquefy/causality
```
